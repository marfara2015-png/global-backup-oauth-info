# GLOBAL Backup Personal — borrador privado

Repositorio exclusivamente informativo para el consentimiento OAuth del respaldo privado de Google Apps Script.

- `index.html`: información de la herramienta.
- `privacy.html`: privacidad y conservación de copias.

**No publicar ni activar GitHub Pages hasta revisión expresa.** No incluir código de GLOBAL, credenciales ni respaldos en este repositorio.

Al publicar en GitHub Pages, las páginas serán públicas incluso si la herramienta es de uso privado. Revisar las afirmaciones y el correo publicado antes de hacerlo.
