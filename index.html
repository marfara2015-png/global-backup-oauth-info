GLOBAL Backup Personal

GLOBAL Backup Personal es una herramienta privada de uso individual destinada a realizar copias de seguridad del código fuente de un proyecto propio de Google Apps Script.

Qué hace

Con autorización expresa del titular de la cuenta de Google, utiliza el permiso de solo lectura script.projects.readonly para obtener los archivos del proyecto seleccionado. Su objetivo es conservar una copia de recuperación del código.

Qué no hace

No modifica, ejecuta, elimina ni publica el proyecto de Apps Script mediante ese permiso. No está dirigida al público ni ofrece registro a terceros.

Copias de seguridad

Las copias están previstas para almacenarse cifradas en infraestructura privada de respaldo controlada por el titular. El acceso se limita a la finalidad de copia y recuperación.

Consulta la Política de privacidad para más información. Contacto: marfara2015@gmail.com.
