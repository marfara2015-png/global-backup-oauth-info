Política de privacidad — GLOBAL Backup Personal

Estado: Política de privacidad vigente de GLOBAL Backup Personal.

Finalidad y alcance

GLOBAL Backup Personal es una herramienta privada para conservar copias de seguridad del código de un proyecto de Google Apps Script del propio titular. No se ofrece a usuarios externos.

Datos a los que puede acceder

Con el consentimiento del titular, la herramienta solicita el permiso OAuth https://www.googleapis.com/auth/script.projects.readonly. Este permiso permite leer archivos de proyectos de Google Apps Script a los que la cuenta autorizante tenga acceso. La herramienta está diseñada para consultar únicamente el identificador de proyecto configurado para el respaldo.

Uso de la información

El contenido obtenido se utiliza para producir una copia de seguridad, comprobar su integridad y facilitar una eventual recuperación. No se utiliza para publicidad, perfilado ni venta de datos.

Almacenamiento y acceso

Está previsto que las copias se cifren antes de enviarlas al almacenamiento privado de respaldo. Para realizar la automatización pueden conservarse credenciales OAuth en el sistema de secretos del entorno de ejecución. El acceso a los respaldos y las credenciales debe restringirse al titular y a los servicios técnicos necesarios para estas operaciones.

Servicios utilizados

La herramienta usa las API de Google para consultar el código y prevé utilizar GitHub Actions para ejecutar la copia y Backblaze B2 para el almacenamiento cifrado. Estos proveedores pueden tratar información técnica necesaria para prestar sus servicios, conforme a sus condiciones y políticas propias.

Conservación y eliminación

Las copias cifradas se conservan hasta que el titular decida eliminarlas. La eliminación se gestionará en el almacenamiento de respaldo, respetando los períodos de retención o bloqueo que pudieran estar vigentes. El titular puede revocar el acceso de la herramienta desde la configuración de seguridad de su cuenta Google.
